## פותחים את המשחק במחשב

1. במאגר התבנית לחצו על הכפתור הבא וצרו מאגר בחשבון שלכם.

   **Use this template → Create a new repository**

2. העתיקו את כתובת המאגר שלכם. בחלון הפתיחה של סביבת הפיתוח בחרו בשכפול מאגר והדביקו את הכתובת.

   **Visual Studio → Clone a repository**

3. פתחו את קובץ הפתרון והפעילו את המשחק. נדרשת סביבת פיתוח עם תמיכה בגרסה שמונה של דוטנט.

   **MineEscape.sln → Ctrl+F5**

## משחקים בטלפון

הפרסום בחינם דורש מאגר ציבורי. המשמעות היא שהמשחק והקוד במאגר יהיו זמינים לכולם. הפעילו את הפרסום רק כאשר אתם רוצים לשתף את העבודה בפומבי.

1. במאגר שלכם בחרו במקור הפרסום הבא.

   **Settings → Pages → Build and deployment → Source → GitHub Actions**

2. שלחו את השינויים מהעותק במחשב לענף הראשי.

   **Git Changes → Commit → Push**

3. המתינו להצלחה בדף הרצות הבנייה ופתחו בטלפון את כתובת המשחק.

   **Actions → Publish Mine Escape**

   **Settings → Pages → Visit site**

אם הפעלתם את הפרסום אחרי השליחה האחרונה, הפעילו את התהליך ידנית פעם אחת.

**Actions → Publish Mine Escape → Run workflow**
